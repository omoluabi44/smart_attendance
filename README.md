# Smart Attendance System (Powered by AWS Rekognition) ☁️🛡️

A cloud-integrated attendance management solution that utilizes **Amazon Rekognition** for industry-leading facial recognition .

## 🌟 Key Features
* **Cloud-Native Recognition:** Leverages AWS's deep learning models for high-confidence face matching.
* **S3 Integration:** Securely handles image storage and retrieval using **Amazon S3**.
* **Scalable Collections:** Uses Rekognition Collections to index and search thousands of faces with millisecond latency.
* **Automated Logging:** Seamlessly transitions from cloud-based identification to local CSV/Database attendance logging.

## 🛠 Tech Stack
* **Cloud Provider:** Amazon Web Services (AWS)
* **AI Service:** AWS Rekognition (Face Comparison & Search)
* **SDK:** Boto3 (AWS SDK for Python)
* **Language:** Python 3.x
* **Storage:** Amazon S3
